# It's Poop Again

90s arcade prank-em-up. Billy, Frank, and Jack ring-and-run a suburban street.

Play: [kevinfrei.com/itspoopagain](https://kevinfrei.com/itspoopagain)

- Mobile or keyboard, local 3-player + online drop-in (HOST / JOIN a crew code)
- Fill a bag at the bush, plant it, light it, ring, run
- Old Man Clemens stomps the bag and throws the boot
- Two stages: Westport Lane → Fairway Estates
